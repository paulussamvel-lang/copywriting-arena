# 双模型文案协作 Skill

根据选题和参考稿，让 DSH 与 Gemini 各写三篇中文口播，以统一的六维百分制评分，再由各自作者返修；支持汇总到飞书文档以及在兼容的工作台中对比候选稿。

## 使用

将本目录安装或复制到 Codex 的 `skills/copywriting-arena` 目录，按自己的环境配置 DSH、Gemini、飞书以及可选的 Lulu 工作台。首次运行时提供选题、参考稿、飞书父节点和必要的工具连接。使用示例：

```text
使用 $copywriting-arena，根据本期选题和参考稿，分别生成、评分并返修口播文案。
```

`SKILL.md` 包含完整流程，`references/` 包含提示词与评分标准，`scripts/check_scores.py` 可校验分项和总分。评分维度为钩子 20、场景痛点 20、卖点清晰 15、可信度 15、口语节奏 15、转化 15。

完整流程依赖具体应用、账号权限及其实际提供的接口；安装本 Skill 不会自动安装这些第三方工具，也不包含账户凭据。
